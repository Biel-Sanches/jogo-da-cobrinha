# 🐍 Jogo da Cobrinha

O clássico **Snake** rodando direto no navegador, feito com HTML, CSS e JavaScript puro — sem frameworks, sem bibliotecas.

## 🎮 Como jogar

Acesse **https://biel-sanches.github.io/jogo-da-cobrinha/** e:

- **Setas** ou **WASD** movem a cobra;
- **Espaço** começa, pausa e retoma o jogo;
- No **celular**, arraste o dedo na tela para mudar a direção;
- Cada fruta vale **10 pontos** e a cobra fica um pouco mais rápida;
- Bater na parede ou no próprio corpo encerra a partida;
- Seu **recorde** fica salvo no navegador.

## 🛠️ Tecnologias

- HTML5 (`canvas` para o tabuleiro)
- CSS3 (tema escuro, responsivo, sem pré-processadores)
- JavaScript puro (lógica de jogo, `localStorage` para o recorde, controles por teclado e toque)
